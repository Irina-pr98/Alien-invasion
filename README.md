# Alien Invasion

Alien Invasion - это игра, в которой игрок управляет кораблем, стреляющим по флоту инопланетян. Игра разработана с использованием Python и Pygame.

## Описание игры

В игре **Alien Invasion** игрок управляет кораблем, который появляется в нижней части экрана. Игрок может перемещать корабль влево и вправо с помощью стрелок и стрелять пулями, используя пробел. Когда игра начинается, флот инопланетян заполняет небо и движется по экрану. Игрок должен стрелять и уничтожать инопланетян. Если игрок уничтожит всех инопланетян, появляется новый флот, который движется быстрее предыдущего. Если инопланетянин ударяет корабль игрока или достигает нижней части экрана, игрок теряет корабль. Если игрок теряет три корабля, игра заканчивается.

## Требования

- Python 3.x
- Pygame

## Управление

- **Пробел**: стрелять
- **Стрелки влево/вправо**: перемещать корабль

## Установка и запуск

1. Клонируйте репозиторий
   ```sh
   $ git clone https://github.com/Irina-pr98/Alien-invasion.git
   $ cd Alien-Invasion
   ```

2. Установите зависимости
    ```sh
    $ pip install pygame
    ```

3. Запустите игру
   ```sh
   $ python alien_invasion.py
   ```

## Структура проекта

- `alien_invasion.py`: основной файл для запуска игры
- `settings.py`: настройки игры
- `game_stats.py`: отслеживание статистики игры
- `scoreboard.py`: отображение счета
- `button.py`: создание кнопок
- `ship.py`: управление кораблем игрока
- `bullet.py`: управление пулями
- `alien.py`: управление инопланетянами
- `game_functions.py`: функции для управления игровым процессом
